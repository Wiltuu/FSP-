# 🎯 Objetivo do Projeto

Este projeto tem como objetivo aplicar conceitos teóricos de:

- Finanças Públicas
- Economia
- Contabilidade
- Administração Pública

na análise empírica de dados reais do setor público brasileiro e internacional.

O estudo foi dividido em três frentes principais:

## 🌍 Análise Macro
Estudo de indicadores da **OCDE** aplicados ao **Japão**.

## 🏙️ Análise Micro/Municipal
Avaliação detalhada de **accountability** e execução orçamentária dos municípios de:

- Garanhuns (PE)
- Santana (AP)

## 📈 Diagnóstico Fiscal Integrado — Estado de Pernambuco
Mapeamento e análise **per capita** das receitas e despesas dos **184 municípios pernambucanos**, identificando:

- Falhas de mercado
- Dependência fiscal
- Disparidades regionais

# 💻 Resumo do Script de Tratamento de Dados (Python)

O script desenvolvido em Python realiza:

- Extração das contas de:
  - **RECEITAS (EXCETO INTRA-ORÇAMENTÁRIAS) (I)**
  - **Total Geral da Despesa**
- Integração das bases via:
  - **Código IBGE**
- Cálculo automatizado de:
  - Receita Per Capita
  - Despesa Per Capita
- Geração das bases utilizadas nas visualizações analíticas

Todo o processo foi estruturado visando:

- Reprodutibilidade
- Transparência
- Escalabilidade analítica

> A versão completa e comentada do código está disponível nos apêndices do relatório final.
